# Lightning-Proxy

Lightning-Proxy is een nieuw GitHub-project van [Kaasplank1234](https://github.com/Kaasplank1234). De repository bevat op dit moment nog geen broncode.

## Over het project

Dit project krijgt als doel de ontwikkeling van een Lightning-Proxy. Nadere documentatie, installatie-instructies en gebruiksvoorbeelden worden toegevoegd zodra de eerste implementatie beschikbaar is.

## Aan de slag

Er zijn nog geen installatie- of uitvoerinstructies beschikbaar. Zodra broncode en afhankelijkheden zijn toegevoegd, worden hieronder de benodigde commando's opgenomen.

## Bijdragen

Bijdragen aan dit project zijn welkom. Je kunt:

1. Een issue openen voor een bug, idee of vraag.
2. Een aparte branch maken voor je wijziging.
3. Een pull request indienen met een duidelijke beschrijving.
